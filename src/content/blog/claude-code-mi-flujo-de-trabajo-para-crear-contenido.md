Este sitio que estás leyendo — la estructura, el diseño, cada artículo del blog — lo construí trabajando con Claude Code. No partí de una plantilla cerrada ni de un diseñador externo: le fui dando instrucciones, en español, y Claude Code fue escribiendo el sitio de verdad, archivo por archivo. Te cuento cómo es ese flujo de trabajo en la práctica.

## Respuesta rápida

Claude Code es la herramienta de Anthropic para construir software completo dando instrucciones en lenguaje natural, sin tener que programar tú mismo. Yo la uso para construir y mantener este sitio completo: la estructura, el diseño, los ajustes y cada artículo del blog. Para mí, de todas las herramientas de Claude, es la que más le cambió el juego a mi forma de trabajar.

## Cómo es mi flujo de trabajo, en la práctica

1. **Le describo lo que quiero construir o ajustar**, en lenguaje normal — una sección nueva, un artículo, un cambio de diseño.
2. **Claude Code escribe los archivos reales del sitio.** Este sitio es un proyecto en Astro (sitio estático): cada artículo es un archivo de texto, y el menú, el pie de página y el diseño viven en un solo lugar.
3. **Reviso en vista previa**, en mi computador, antes de que cualquier cambio quede publicado.
4. **Cuando lo apruebo, se publica** a través de GitHub y Vercel: el código queda guardado con historial, y el sitio se actualiza solo.
5. **Si algo no quedó como quería, se lo digo** y Claude Code lo ajusta — es un proceso de ida y vuelta, no de una sola instrucción mágica.

## Mi experiencia: de "asistente que redacta" a "asistente que construye"

Vengo usando IA para mi negocio desde hace tiempo, pero el salto que más noté fue este: pasar de un asistente que te redacta texto a uno que te construye cosas de verdad. Con Claude Code paso de darle una instrucción a tener una página, una sección o un artículo funcionando — sin tener que saber programar de fondo. Esa es, en mi experiencia, la diferencia más grande frente a usar solo el chat.

Lo que más valoro es que no tengo que depender de un desarrollador ni de un diseñador para cada cambio pequeño: puedo iterar yo mismo, en el momento, revisando siempre antes de que algo quede público. Eso es justo lo que me permitió construir este sitio completo sin partir de cero en código.

## Errores comunes al empezar con Claude Code

- **Pensar que necesitas saber programar primero.** No es el requisito — sí ayuda ser claro con lo que quieres.
- **Dar instrucciones muy generales** ("mejora el sitio") en vez de concretas ("cambia el color del botón del menú a amarillo"). Entre más específico seas, mejor el resultado.
- **Publicar sin revisar en vista previa.** Siempre reviso los cambios antes de que lleguen al sitio público — esa revisión final sigue siendo mía.
- **Pedir todo en un solo mensaje gigante** sin dar espacio a ajustar sobre la marcha. A mí me funciona mejor ir probando y corrigiendo que intentar que todo salga perfecto a la primera.
